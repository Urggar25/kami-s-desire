# Ambient corridor encounters
10% independent chance per eligible corridor arrival (not screen redraws or return from optional conversations). Navigation remains clickable; no dialogue, no changes to story flags, no camera or master-layer sprite changes. Five finite motions: stride, greet (smile/nod, no hand animation), rush, linger, recede (quiet lateral exit, no depth shrink). Existing sprites, no new art. No repeat of last actor. First rollout days 1–6 only, excludes night and scripted encounter corridors/unknown scripted routes to avoid continuity errors. Later days require route-specific availability lists. Disable with persistent.kd_corridor_ambient_enabled = False. Motion is stylized sprite translation without exaggerated bob, not articulated walking or true back view. No material-carrying asset added. Ren'Py 8.3.7 runtime/lint not executed.
