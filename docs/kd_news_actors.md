# Modular TV actors

20 presets; four skin layers, six hair shapes in six palettes, eight outfits, five brow expressions, three eye states, seven mouth states, glasses and microphone. Vector assets are original stylized placeholders, replaceable with art of identical canvas/registration.

Use `$ kd_news_stage("interview", "reporter", "mother")`, then `kd_tv_reporter "Question ?"`. Set expression with `$ kd_news_expression("mother", "sad")`. New profiles: `$ kd_news_configure("guest", skin=2, hair=1, hair_color=0, outfit=4)`. Define a Character using kd_news_character for custom speakers. Layouts: studio, interview, duplex, debate, home, flash, insert (single portrait over existing CG). Close through kd_news_close or kd_news_leave_view. Demo label: kd_news_actor_demo. No runtime image writes. Test under Ren'Py 8.3.7 before release.
